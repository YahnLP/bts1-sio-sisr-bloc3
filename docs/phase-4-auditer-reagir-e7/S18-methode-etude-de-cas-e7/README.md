> [!NOTE]
> **Question qui guide la séance :** *« Comment répondre à une étude de cas écrite de quatre heures en s'appuyant sur un dossier documentaire ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Lire** un dossier documentaire et **repérer** les faits utiles (chiffres, règles, outils en place) ;
2. **Identifier** le type de chaque question (qualifier, proposer, justifier, comparer, rédiger) ;
3. **Structurer** une réponse : risque, mesure, justification, limite ;
4. **Gérer** le temps d'une épreuve de quatre heures ;
5. **Faire le lien** entre une question d'étude de cas et les séances du bloc.
