# Aide-mémoire – Méthode de l'étude de cas et synthèse du bloc

*BTS SIO SISR 1re année – Bloc 3 – S18*

> Un mot ou un sigle inconnu ? Passe la souris dessus, ou ouvre le [glossaire](../../ressources/glossaire.md).

## Méthode en 5 temps

1. **Lire** tout le sujet (15-20 min), surligner, remplir la fiche de repérage.
2. **Repérer le verbe** de chaque question.
3. **Répondre** avec **RMJL** : Risque · Mesure · Justification · Limite.
4. **Citer** le dossier à chaque réponse.
5. **Relire** (20 min) : une réponse argumentée par question.

## Verbes

| Verbe | Réponse |
|---|---|
| Identifier | Liste sourcée |
| Qualifier | Terme exact + justification |
| Proposer | Mesure précise, adaptée |
| Justifier | Risque évité, argument du dossier |
| Comparer | Tableau + choix |
| Prioriser | Ordre + critère |
| Rédiger | Format imposé |
