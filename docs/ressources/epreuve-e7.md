# L'épreuve E7 et la préparation

> [!NOTE]
> Page à relire sur les textes officiels : l'arrêté du 8 juillet 2024 (annexes sur les épreuves) et la circulaire nationale restent la référence. Cette page résume ce que la formation prépare.

## Le format

| Élément | Détail |
|---|---|
| **Intitulé** | Cybersécurité des services informatiques |
| **Numéro** | **E7** (unité U7) dans l'arrêté du 8 juillet 2024. Dans les anciens documents, la cybersécurité portait un autre numéro (E6) : les supports antérieurs à 2024 peuvent encore s'en servir. |
| **Forme** | Épreuve **ponctuelle écrite**, il n'y a pas de contrôle en cours de formation |
| **Durée** | **4 heures** |
| **Coefficient** | 4 |
| **Support** | Une **étude de cas** de production de services informatiques sécurisés, construite à partir d'une situation réelle |
| **Correction** | Assurée par un enseignant en charge d'un bloc professionnel de la section |

## Comment est construit le sujet

Le texte officiel décrit une étude de cas composée de **plusieurs dossiers** couvrant différentes missions d'infrastructure, systèmes et réseaux, avec un **dossier documentaire** qui présente :

- le contexte de l'organisation ;
- les solutions applicatives et d'infrastructure en place ;
- les moyens techniques, humains et financiers disponibles ;
- le cadre juridique ;
- l'expression des besoins qui motivent les services demandés.

Les critères d'évaluation sont les **critères de performance** des cinq compétences du bloc (voir le [référentiel](referentiel.md)). Le barème exact n'est pas fixé dans cette page : il dépend de chaque sujet.

## Ce que le sujet demande de savoir faire

| Situation | Exemples de travail attendu |
|---|---|
| Lire un dossier documentaire | Repérer les risques, les traitements de données, les failles de l'architecture |
| Appliquer le cadre juridique | Qualifier un traitement, un incident, une obligation de notification, une responsabilité |
| Proposer des mesures | Segmentation, droits, chiffrement, sauvegarde, journalisation, durcissement, VPN |
| Justifier | Pourquoi cette mesure, pourquoi pas une autre, quel coût, quelle priorité |
| Communiquer | Rédiger une note claire pour un dirigeant, un compte rendu d'incident |

## Ce que la formation prépare, séance après séance

| Étape | Séances | Production |
|---|---|---|
| Acquérir les notions et les réflexes | S01 à S17 | Bilans et rendus de TP |
| Apprendre la méthode de l'étude de cas | S18 | Étude de cas guidée, corrigée en séance |
| S'entraîner dans les conditions de l'examen | S19 | Épreuve blanche de 4 h, sujet complet avec dossier documentaire |

## Méthode de travail pendant l'épreuve

1. **Lire tout le sujet** (15 minutes) : repérer les dossiers, les annexes, le barème s'il est indiqué.
2. **Surligner** les faits utiles du dossier documentaire (chiffres, noms de serveurs, règles).
3. **Répondre dossier par dossier**, en citant le document source (« d'après l'annexe 2… »).
4. Pour chaque proposition : **risque → mesure → justification → limite**.
5. **Relire** : chaque question a-t-elle une réponse argumentée ?

> [!WARNING]
> Une réponse qui ne s'appuie pas sur le dossier documentaire est une réponse de cours : elle rapporte peu. Cite les éléments du contexte (taille de l'entreprise, budget, outils déjà présents).
