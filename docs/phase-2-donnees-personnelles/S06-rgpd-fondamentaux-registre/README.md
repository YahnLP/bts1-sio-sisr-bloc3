## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Définir** donnée à caractère personnel, donnée sensible, traitement, responsable de traitement, sous-traitant et destinataire ;
2. **Situer** les acteurs : CNIL, délégué à la protection des données (DPO), personne concernée ;
3. **Énoncer** les principes de l'article 5 du RGPD et les **illustrer** sur des cas ;
4. **Recenser** les traitements d'une organisation et **renseigner** un registre ;
5. **Retrouver** des données personnelles dans un espace de stockage avec des recherches ciblées ;
6. **Repérer** les écarts de conformité d'une situation décrite et **proposer** une mesure.
