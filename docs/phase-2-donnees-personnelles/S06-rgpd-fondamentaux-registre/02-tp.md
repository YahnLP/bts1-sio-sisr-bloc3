# TP – Recenser les traitements de données personnelles d'une PME

*BTS SIO SISR 1re année – Bloc 3 – S06*

> [!NOTE]
> **But.** Situation : Quelles données personnelles circulent dans l'entreprise, qui est responsable de quoi, et comment le prouver ?
>
> **Comment ce TP fonctionne.** Avant de manipuler, tu écris ce que tu **anticipes** (« J'anticipe »). Puis tu testes et tu notes ce que tu **constates**. Tu **comprends** ce que fait chaque commande (« Je comprends »). Un **bilan de compétences** clôt la séance. Les manipulations se font sur des **machines virtuelles de laboratoire**, isolées du réseau de l'établissement. Les identifiants communs d'un TP sont des **identifiants de laboratoire** : ils ne se réutilisent jamais ailleurs.

## Objectif

Recenser les traitements de données personnelles d'une PME à partir de la description de son système d'information, renseigner son registre, retrouver des données personnelles dans un partage, puis analyser les écarts de conformité d'un cabinet médical.

## Contraintes

- Binôme, durée : 3 h 10.
- Toutes les entreprises et données de ce TP sont **fictives**. Ne cherche pas de vraies données personnelles.
- Les recherches de la partie B se font **uniquement** dans le dossier de laboratoire créé pour l'occasion.

## Partie B. Retrouver des données personnelles (50 min)

Dans la VM Debian, crée le partage de laboratoire avec le script suivant (toutes les données sont **inventées**). Enregistre-le sous `gen-partage.sh` puis lance-le.

```bash
#!/bin/bash
D=~/partage-labo
mkdir -p "$D"/{commercial,rh,compta,divers}
cat > "$D/commercial/clients-2019.csv" <<'EOF'
nom;prenom;email;telephone
Durand;Alice;alice.durand@example.com;06 00 00 00 01
Martin;Bruno;b.martin@example.org;0600000002
Petit;Chloé;chloe.petit@example.net;+33 6 00 00 00 03
EOF
cat > "$D/commercial/notes-appel.txt" <<'EOF'
Rappeler M. Leroy (david.leroy@example.com) au 06.00.00.00.04 avant vendredi.
Il souhaite un devis pour 12 postes. Remise accordée : 5 %.
EOF
cat > "$D/rh/arrets.txt" <<'EOF'
Arrêt maladie de Mme Garcia du 12 au 26 mars (certificat reçu).
Contact : emma.garcia@example.com
EOF
cat > "$D/rh/fiche-paie-modele.txt" <<'EOF'
Salarié : Farid Haddad
N° de sécurité sociale : 1 00 00 00 000 000 00
IBAN : FR76 0000 0000 0000 0000 0000 000
EOF
cat > "$D/compta/virements-fournisseurs.txt" <<'EOF'
Fournisseur bois : IBAN FR76 1111 1111 1111 1111 1111 111
Fournisseur quincaillerie : contact@example.com
EOF
cat > "$D/divers/idees-fete.txt" <<'EOF'
Organiser la fête de fin d'année. Budget : 600 euros. Aucune donnée personnelle ici.
EOF
echo "Partage de laboratoire créé dans $D"
```

Lance ensuite les recherches :

```bash
grep -rEoh '[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}' ~/partage-labo | sort | uniq -c
grep -rEn '(\+33 ?|0)[1-9]([ .]?[0-9]{2}){4}' ~/partage-labo
grep -rEn 'FR[0-9]{2}( ?[0-9A-Z]{4}){5} ?[0-9A-Z]{3}' ~/partage-labo
grep -rEn '[12] ?[0-9]{2} ?[0-9]{2} ?[0-9]{2} ?[0-9]{3} ?[0-9]{3} ?[0-9]{2}' ~/partage-labo
grep -rEil 'arrêt maladie|certificat' ~/partage-labo
```

**Je comprends.**

| Option ou motif | Rôle |
|---|---|
| `grep -r` | Cherche **récursivement** dans tous les fichiers du dossier |
| `-E` | Active les **expressions régulières étendues** |
| `-o`, `-h` | Affiche **seulement** la partie qui correspond, sans nom de fichier |
| `-n` | Ajoute le **numéro de ligne** |
| `-i`, `-l` | Insensible à la casse ; liste seulement les **fichiers** concernés |
| `[A-Za-z0-9._%+-]+@...` | Un motif de **courriel** |
| `(\+33 ?\|0)[1-9]([ .]?[0-9]{2}){4}` | Un **numéro de téléphone** français sous plusieurs écritures |
| `FR[0-9]{2}( ?[0-9A-Z]{4}){5} ?[0-9A-Z]{3}` | Un **IBAN** français |
| `[12] ?[0-9]{2}...` | Un numéro de **sécurité sociale** (15 chiffres) |

**J'anticipe.** Les recherches par motifs vont-elles trouver **tous** les noms de personnes du partage ? ______________________

<details markdown="1">
<summary>Éléments de réponse</summary>

**Non** : un nom n'a pas de forme reconnaissable (« Leroy », « Garcia »). Les motifs trouvent les données **à format fixe** (courriel, téléphone, IBAN, numéro de sécurité sociale) ; pour le reste, il faut une recherche par mots-clés, un examen manuel, ou un outil de découverte de données. C'est une **aide à l'inventaire**, pas une garantie.

</details>
